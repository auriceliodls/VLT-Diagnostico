É necessário utilizar a última revisão deste catálogo para efetuar a compra de peças sobressalentes. 
Use somente peças originais  KNORR-BREMSE . 
 
Informações gerais 
O Catálogo de Peças Sobressalentes – uma compilação dos desenhos e listas de peças – é uma 
forma eficiente de se encontrar os códigos de todas as peças que compõem o sistema de porta.  
 
Como usar este catálogo 
O índice lista todas as vistas explodidas dos conjuntos que compõem o sistema de porta juntamente 
com a sua página correspondente. Para achar um código específico, deve-se procurar na vista 
explodida o número de ordem da peça e buscar o código na lista de peças subseqüente.
